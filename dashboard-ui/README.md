# Dashboard UI

Control condition for the MA study: a normal filter-and-sort flight search over the same synthetic dataset. React, Vite, TypeScript, Tailwind. No LLM / API key.

## Setup

```bash
npm install
npm run prebuild   # copies ../data CSV into public/
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

To regenerate the dataset, see the root `README.md`.

## Shortcut

- **Shift + E** — export session log (filters, card clicks, detail views)
